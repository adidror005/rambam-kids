# Torah for Every Reader · תורה לכל גיל

**A deployable, dependency-free GitHub Pages prototype** for reading the *Mishneh Torah* in three versions:

- Original Hebrew (with niqqud when present)
- Kid-friendly Hebrew (with niqqud when present)
- Kid-friendly English
- An optional three-column comparison view

The site **works before all texts are available**. Every chapter is a separate JSON file, and every language can be missing on a segment-by-segment basis. Missing text is labelled clearly rather than silently replaced by a different version.

## Try locally (no npm, no Python dependencies to view)

From the repository root:

```bash
python -m http.server 8000 --directory docs
```

Open <http://localhost:8000>. The included miniature demo deliberately has incomplete translations to illustrate the fallback UI.

## 1. Add the complete JSON you already have

Save the JSON of `Mishneh Torah, Slaves 4` that you generated to a local file, e.g. `slaves4.json`, then run:

```bash
python scripts/import_chapter.py slaves4.json --he-title "הלכות עבדים"
```

That's it. The importer understands your **existing exact structure**:

```json
{
  "ref": "Mishneh Torah, Slaves 4",
  "version_title": "Torat Emet 363",
  "segments": {
    "1": {
      "ref": "Mishneh Torah, Slaves 4:1",
      "original_hebrew": "...",
      "kids_hebrew": "...",
      "kids_english": "...",
      "niqqud_coverage": 1.0
    }
  },
  "complete": true
}
```

The importer merges by `ref` and numbered segment. It **adds/updates non-empty translated fields** without deleting other segments or translations. By default it keeps the existing original Hebrew if already downloaded; use `--overwrite-original` to deliberately replace the stored source with your edition. The `complete` flag is not trusted for coverage; the site counts what's actually present.

## 2. Download all ORIGINAL Hebrew text from Sefaria

**One command downloads every Mishneh Torah book and its chapters:**

```bash
python scripts/fetch_sefaria.py --all
```

This retrieves the book list from Sefaria's Table of Contents API, obtains each book's chapter count via the Shape API, then requests original Hebrew chapter by chapter from the Texts v3 API. Sefaria's APIs do not require a key. The book catalog is cached in `work/mishneh_torah_catalog.json`, so later runs do not have to rediscover every chapter. The site works with *whatever has been downloaded so far*.

**For prototyping, download just ten NEW chapters per run:**

```bash
python scripts/fetch_sefaria.py --all --limit 10
```

Run **the same command again** to fetch the next ten. `--limit` counts only chapters that aren't already cached, not the chapters that were skipped. You can interrupt with Ctrl+C, safely resume, or simply run `--all` again to complete the remainder.

For a preview without downloading chapter texts (catalog discovery still requires network on the first run):

```bash
python scripts/fetch_sefaria.py --all --dry-run --limit 10
```

For a single book or chosen chapter range, the old commands still work:

```bash
python scripts/fetch_sefaria.py --book "Mishneh Torah, Slaves" \
  --he-title "הלכות עבדים" --chapters 1 2 3 4 5

python scripts/fetch_sefaria.py --book "Mishneh Torah, Slaves" \
  --start 1 --end 9
```

**What is cached?** Every successful chapter gets a `source_download` checkpoint identifying the requested edition and saved segments. The downloader skips that chapter on subsequent runs, without even making the chapter request. A manually imported, possibly partial chapter may be fetched once to establish a verified checkpoint; the existing kid-friendly versions are preserved. Translations are never regenerated by this downloader.

Optional flags:

```bash
# Use Sefaria's source text instead of the named edition
python scripts/fetch_sefaria.py --all --primary

# Explicitly refetch all source text (kid-friendly text is still preserved)
python scripts/fetch_sefaria.py --all --refresh

# Discover the latest book/chapter list from Sefaria again
python scripts/fetch_sefaria.py --all --refresh-catalog

# Slow down chapter requests if needed
python scripts/fetch_sefaria.py --all --delay 1
```

By default the chosen edition is **Torat Emet 363**, matching your example. If that edition isn't available for a given chapter, the downloader reports an error rather than silently mixing editions. `--primary` is an alternative that uses Sefaria's source edition; switching editions makes it necessary to download that chapter again, but it still preserves your kid-friendly content. Retries are enabled for temporary network/server errors and requests are spaced apart to be respectful of Sefaria.

Every successful chapter is saved immediately into `docs/data/books/.../CHAPTER.json` and is added to `docs/data/manifest.json`, ready to commit and publish. A failed chapter doesn't undo earlier ones. **Note:** this prototype's API integrations have been validated with offline tests/mocked responses, not a live full-corpus run. Test `--all --limit 2` before starting the whole download. Check each Sefaria edition's redistribution license before publishing.

## 3. Generate missing versions incrementally

```bash
# One chapter only
python scripts/list_missing.py --chapter 4

# Everything downloaded so far (all books)
python scripts/list_missing.py --all

# A small trial batch of missing translations
python scripts/list_missing.py --all --limit 50
```

This writes `work/missing.jsonl`, where each line contains a missing `kids_hebrew` or `kids_english` field and its original Hebrew source. Feed any subset into your existing LLM generation notebook/script, then import its chapter-shaped JSON response with `import_chapter.py`:

```json
{
  "ref": "Mishneh Torah, Slaves 4",
  "segments": {
    "9": {"kids_hebrew": "..."},
    "10": {"kids_english": "..."}
  }
}
```

You do **not** need to regenerate completed segments. For changes to kid-friendly texts, import another partial file: only those fields change. If you want to automate generation next, make a small worker that consumes `missing.jsonl`, writes valid JSON to disk after each generated segment, and imports each batch. Keep model keys in local environment variables or secure CI secrets — never in `docs/` or the public GitHub repository. Consider a review step for each adaptation before calling it approved.

## 4. Publish to GitHub Pages immediately

1. Create a **public GitHub repository**, such as `torah-for-every-reader`, and push these files to the `main` branch.
2. Open **Settings → Pages → Build and deployment → Deploy from a branch**.
3. Select branch **`main`**, folder **`/docs`**, then **Save**.
4. The site will appear at `https://YOUR_USERNAME.github.io/torah-for-every-reader/` (or the repo's configured Pages URL).

No Vite or GitHub Actions are needed. This prototype uses relative asset URLs so it works on both repository and custom-domain Pages paths. After each new chapter import/download, commit and push the JSON and manifest changes.

## Data layout

```text
.
├── docs/
│   ├── index.html
│   ├── app.js
│   ├── styles.css
│   └── data/
│       ├── manifest.json          # Autogenerated navigation and completeness counts
│       └── books/
│           └── mishneh-torah-slaves/
│               ├── 4.json         # A chapter, independently publishable
│               └── 5.json         # Added later — no migration required
├── scripts/
│   ├── common.py
│   ├── import_chapter.py
│   ├── fetch_sefaria.py     # --all, --limit, --refresh and catalog discovery
│   └── list_missing.py     # --all missing versions across books
└── tests/
```

The reader fetches the manifest **once**, then loads **only the selected chapter JSON**. No giant monolithic data payload; additions to one chapter do not require regenerating unrelated chapters.

## A note about accuracy and licensing

The kid-friendly texts are **adaptations**, not exact translations. Some legal details in historical halachic texts are complex, sensitive, or easy for an LLM to misstate; review them against the original with a qualified educator before publicly representing them as reliable educational editions. Preserve original source/version attribution and check the specific Sefaria edition's license/redistribution terms. A complete-looking niqqud coverage score says nothing about halachic correctness.
